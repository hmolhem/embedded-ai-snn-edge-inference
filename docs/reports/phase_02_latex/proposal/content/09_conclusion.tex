\section{Conclusion}

Phase 2 will continue the completed Phase 1 DOA/SNN project by converting the controlled proof-of-concept into a more robust radar/DOA sensing case study. The main scientific question is whether the Phase 1 spike-based temporal inference path remains useful when the sensing data become harder and more realistic.

The proposed work preserves the core Phase 1 pipeline while adding controlled stress tests, richer feature comparisons, and stricter reproducibility. This provides a defensible bridge from Python-based embedded-AI experimentation toward later PYNQ, FPGA, and Vitis HLS implementation.

The immediate next step is to finalize the Phase 2 repository skeleton, generate Run 001 as a Phase 1 reproduction check, and then incrementally add harder sensing conditions in numbered, well-documented runs.
