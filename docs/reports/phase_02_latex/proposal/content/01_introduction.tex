\section{Introduction and Motivation}

Autonomous and robotic edge platforms must convert sensor measurements into actionable information under constraints on computation, memory, communication bandwidth, and decision time. In many directional-sensing tasks, the immediate requirement is not a continuously resolved high-precision angle estimate. A coarse but reliable direction sector can serve as a perception primitive for sensor steering, search prioritization, target-oriented attention, or downstream control logic. This narrower task is especially relevant when the sensing node must operate locally and cannot depend on a large general-purpose inference model or continuous cloud connectivity.

Array sensing provides a physically structured basis for this problem. The relative phase and spatial correlation observed across a uniform linear array contain direction-dependent information that can be represented through the sample covariance matrix and projected into a compact beamspace feature vector. Classical high-resolution methods such as MUSIC remain important references for DOA estimation~\cite{schmidt1986music}; however, the present project does not seek to replace such estimators with an opaque neural model. Its focus is the lower-complexity question of whether physically derived spatial features can support reliable sector-level decisions through a compact, interpretable, and hardware-oriented inference path.

Spike-based processing is relevant to this objective because it converts continuous feature magnitudes into sparse temporal events and exposes decision formation over time. Spiking and neuromorphic-computing research has established the broader potential of event-driven representations and stateful temporal processing~\cite{maass1997networks,roy2019towards,schuman2022opportunities}. Nevertheless, sparsity alone does not establish engineering value. A task-specific system must quantify the accuracy lost during spike encoding, the number of events required, the time needed for a stable decision, and the conditions under which temporal inference becomes unreliable. These measurements are central to the present study.

Phase 1 created the required reference system rather than a generic sensing demonstration. It implemented an end-to-end DOA-sector pipeline consisting of narrowband ULA simulation, sample-covariance estimation, beamspace feature extraction, nearest-centroid continuous classification, rate-based spike encoding, and LIF-inspired temporal evidence accumulation~\cite{molhem2026phase1}. The Phase 1 experiments established that the spike-based path could retain most of the continuous baseline accuracy while introducing measurable spike activity and stable-decision latency. They also demonstrated that the LIF time window and leak factor define a controllable accuracy--latency tradeoff.

The Phase 1 design was intentionally nominal. It used a single-source, eight-element ULA with half-wavelength spacing, four fixed angular sectors, 128 snapshots per sample, and an SNR range from $-10$ to $20$~dB. Source angles were sampled across each sector, but angular distance from the decision boundaries was not treated as an independent stress variable. The test data also assumed that the array manifold used for feature extraction matched the array that generated the observations. Consequently, Phase 1 established feasibility but did not determine how the method behaves near classification boundaries, below the original SNR range, or under realistic gain/phase perturbations.

Phase 2 addresses this unresolved robustness question while preserving direct comparability with Phase 1. The same sector definitions, covariance stage, beamspace representation, continuous baseline, spike encoder, and LIF-inspired accumulator will be retained. New experiments will isolate three sources of sensing difficulty: low SNR, angular proximity to a sector boundary, and controlled array-model mismatch. The spike-based path will be evaluated against both the Phase 1 continuous classifier and a classical array-processing reference mapped to the same sector labels.

The central research question is therefore:

\begin{quote}
How robust is the completed Phase 1 spike-based DOA-sector inference pipeline to low SNR, sector-boundary ambiguity, and modest array-model mismatch, and how does its accuracy--latency behavior compare with classical and continuous-valued inference references?
\end{quote}

This formulation keeps Phase 2 aligned with the original project trajectory. It does not restart the work, broaden it into a complete radar processor, or claim a new high-resolution DOA algorithm. Instead, it converts the validated Phase 1 prototype into a controlled engineering benchmark capable of identifying a defensible operating region for later embedded deployment.
