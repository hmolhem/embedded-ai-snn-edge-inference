\section{Conclusion}

Phase 2 will extend the completed Phase 1 DOA-sector inference prototype into a more robust radar/array sensing case study. The work will preserve the Phase 1 pipeline while expanding the experimental conditions and evaluation metrics. The main contribution will be a clearer engineering assessment of whether spike-based temporal inference remains useful when the sensing task becomes more challenging.

The expected outcome is a reproducible and defensible Phase 2 prototype that connects array signal processing, classical baseline inference, spike-based temporal representation, stable-decision latency, and embedded-AI design considerations. This will provide a stronger foundation for later hardware-aware work using PYNQ, FPGA, or Vitis HLS.
