# Figures

This folder is reserved for figures used by the Phase 2 proposal or report.

If the KSU logo is needed for the title page, place it here as:

```text
figures/KSU.png
```

Generated experiment figures should use run-numbered names such as:

```text
run_001_phase2_accuracy_vs_snr.png
run_001_phase2_confusion_matrix.png
```
