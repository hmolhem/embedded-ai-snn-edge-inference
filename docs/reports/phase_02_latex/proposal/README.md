# Phase 2 Proposal LaTeX Package

This folder contains the Phase 2 proposal written using the established report-template structure.

## Template Structure

```text
main.tex
README.md
references.bib
setup/
frontmatter/
content/
appendices/
appendices/console_outputs/
codes/
figures/
```

The folder structure is intentionally kept consistent with the user's LaTeX report template. Project-specific folders such as `cst_setup/` are not included because Phase 2 is a Python/radar/embedded-AI proposal, not a CST-based RF simulation report.
