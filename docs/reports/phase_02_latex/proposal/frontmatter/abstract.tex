\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Phase 1 established a reproducible Python reference pipeline for coarse direction-of-arrival (DOA) sector inference using an eight-element uniform linear array, sample-covariance estimation, beamspace feature extraction, a nearest-centroid continuous-valued classifier, rate-based spike encoding, and leaky-integrate-and-fire (LIF)-inspired temporal evidence accumulation. The continuous baseline achieved an overall test accuracy of 86.90\%, while the best Phase 1 LIF configuration achieved 84.17\%, corresponding to approximately 96.8\% accuracy retention relative to the continuous baseline. The spike-based path did not improve raw accuracy; its engineering value was the introduction of sparse temporal processing, measurable stable-decision latency, and a tunable accuracy--latency operating space.

This proposal defines Phase 2 as a direct robustness and comparative-evaluation extension of that completed baseline. The same ULA geometry, sector definitions, covariance-based preprocessing, beamspace representation, and spike-inference architecture will be retained. The sensing problem will then be stressed systematically through an extended low-SNR regime, controlled angular proximity to sector boundaries, and calibrated levels of array gain/phase mismatch. Three inference paths will be compared: a classical array-processing reference mapped to the same sector labels, the Phase 1 nearest-centroid classifier, and the Phase 1 LIF-inspired temporal classifier.

The central research question is whether the spike-based path remains technically defensible as sensing ambiguity increases, and how its accuracy retention, stable-decision latency, and spike activity change relative to the continuous and classical references. Evaluation will include accuracy versus SNR, accuracy versus boundary distance, confusion structure, robustness loss, latency distributions, spike-count statistics, and accuracy--latency Pareto behavior. The expected result is not a claim of a new high-resolution DOA estimator, but a controlled benchmark that identifies where spike-based sector inference remains useful, where it fails, and which operating point is sufficiently accurate and temporally efficient to justify later deployment on a resource-constrained PYNQ, FPGA, or Vitis HLS platform.
