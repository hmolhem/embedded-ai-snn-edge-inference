\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This proposal defines Phase 2 of the embedded-AI DOA/SNN project. Phase 1 established a controlled Python reference prototype for DOA-sector inference using a uniform linear array, sample covariance matrices, beamspace features, a nearest-centroid baseline, rate-based spike encoding, and LIF-inspired temporal accumulation. The main Phase 1 result was that the continuous baseline achieved the strongest raw accuracy, while the spike-based path introduced sparse temporal inference, stable-decision latency, and tunable accuracy--latency behavior.

Phase 2 extends this result into a more robust radar/DOA sensing case study. The proposed work will preserve the Phase 1 inference pipeline while increasing the difficulty of the sensing problem through harder SNR regimes, angular boundary cases, alternative covariance-derived features, and optional classical DOA reference estimators such as MUSIC. The goal is to determine whether the spike-based temporal inference path remains defensible when the input statistics become more challenging. The expected outcome is a reproducible experimental framework with clear metrics for accuracy, latency, spike count, sparsity, and robustness loss relative to Phase 1. This proposal also defines the documentation, result-storage, and reporting plan for the Phase 2 final report.
