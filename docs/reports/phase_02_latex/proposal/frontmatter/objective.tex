\chapter*{Objective}
\addcontentsline{toc}{chapter}{Objective}

The objective of this Phase 2 proposal is to define a scientifically connected continuation of the completed Phase 1 DOA/SNN reference prototype. Phase 1 demonstrated a controlled single-source ULA pipeline using sample covariance estimation, beamspace features, nearest-centroid classification, rate-based spike encoding, and LIF-inspired temporal inference. Phase 2 will not start a separate project; instead, it will stress-test and extend that same pipeline under richer radar/DOA sensing conditions.

The proposed work will evaluate whether the Phase 1 spike-inference path remains useful when the sensing scenario becomes more realistic, more ambiguous, and more demanding. The core deliverables will be reproducible Python experiments, accuracy/latency/sparsity analysis, and a report-ready technical interpretation prepared using the established LaTeX report template.
