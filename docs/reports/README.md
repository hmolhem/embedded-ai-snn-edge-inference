# Reports

This folder is the repository-level entry point for formal course reports, internal technical reports, proposal packages, paper-style drafts, presentations, and supporting report documentation.

## Active Structure

```text
phase_01_latex/                  Completed Phase 1 proposal, report, paper, presentation, and transcript
phase_02_latex/proposal/         Current Phase 2 proposal LaTeX package
```

Each report package should keep its source files, references, figures, appendices, and package-specific README together. Report-specific compilation and synchronization instructions belong in the README inside that package.

## Documentation Rule

Use this folder for maintained report deliverables, not for temporary placeholders. Early planning notes that have been superseded by completed LaTeX packages should be removed rather than left as ambiguous active documents.

## Recommended Technical Coverage

A complete technical report normally includes:

- objective and research question;
- background and prior work;
- signal or system model;
- methodology and implementation;
- experimental design;
- results and engineering interpretation;
- limitations and scope boundaries;
- reproducibility information;
- future hardware or deployment path.

The detailed repository history is maintained in `../handoffs/` and `../project_log.md`.
