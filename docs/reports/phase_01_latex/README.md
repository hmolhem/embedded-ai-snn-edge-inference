# Phase 1 LaTeX Deliverables

This folder contains the first LaTeX draft package for Phase 1 of the embedded-AI DOA/SNN project.

## Files

| File | Purpose |
|---|---|
| `phase_01_proposal.tex` | Proposal for Phase 1 scope, motivation, method, and expected deliverables. |
| `phase_01_report.tex` | Full technical report draft for Phase 1 results. |
| `phase_01_ieee_paper.tex` | IEEE conference-style paper draft for Phase 1. |
| `phase_01_presentation.tex` | Beamer presentation slide deck. |
| `phase_01_presentation_transcript.tex` | Speaker transcript for the presentation. |

## Compile Examples

Run these commands from this folder if a LaTeX distribution is installed:

```powershell
pdflatex phase_01_proposal.tex
pdflatex phase_01_report.tex
pdflatex phase_01_ieee_paper.tex
pdflatex phase_01_presentation.tex
pdflatex phase_01_presentation_transcript.tex
```

The report, IEEE paper, and presentation reference figures from:

```text

```
