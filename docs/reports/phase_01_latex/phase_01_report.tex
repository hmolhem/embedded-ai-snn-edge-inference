\begin{abstract}
This report documents Phase 1 of an embedded-AI project focused on lightweight spike-based inference for edge sensing. A complete Python reference prototype was developed for direction-of-arrival (DOA) sector classification using a physics-based uniform linear array (ULA) signal model. The processing chain includes covariance estimation, beamspace feature extraction, feature normalization, nearest-centroid baseline classification, rate-based spike encoding, and leaky-integrate-and-fire (LIF)-inspired temporal inference. The nearest-centroid baseline achieved an overall test accuracy of $0.869048$. A fixed LIF configuration achieved $0.825000$ accuracy with a mean stable-decision latency of $6.423810$ time steps. A later LIF parameter sweep improved the best LIF accuracy to $0.841667$ at $T=40$ and leak $=0.99$. These results demonstrate a clear and controllable accuracy--latency trade-off, which is central to the embedded AI motivation of the project. The spike-based path is not presented as an accuracy-improving replacement for the continuous baseline; its added value is architectural, converting continuous beamspace classification into a sparse temporal inference process with measurable stable-decision latency and tunable accuracy--latency behavior.
\end{abstract}

\section{Purpose and Scope}

The purpose of Phase 1 is to establish a complete and reproducible Python reference model for DOA-sector inference using a physics-based sensing model and a hardware-aware spike-based inference path. This phase is not intended to introduce a new high-resolution DOA algorithm. Instead, it provides an engineering baseline that can later be refactored toward embedded execution, PYNQ deployment, or Vitis HLS acceleration. This report is prepared as part of the EE 6900 Embedded AI project deliverable sequence~\cite{ee6900_phase1_project}.

The completed prototype connects three technical layers:

\begin{enumerate}[label=\arabic*.]
    \item array signal processing through a ULA signal model and covariance-derived beamspace features,
    \item machine-learning baseline evaluation through nearest-centroid classification,
    \item sparse temporal inference through rate-based spike encoding and LIF-inspired evidence accumulation.
\end{enumerate}

The complete Phase 1 source code, generated metrics, figures, and compiled deliverables are maintained in the project repository~\cite{molhem2026embeddedai}.

\section{Theoretical Background}

This section summarizes the theoretical foundation used in Phase 1. The purpose is to keep the main report self-contained while avoiding unnecessary derivation detail in the main body. The array-processing formulation follows standard ULA and covariance-based signal-processing theory~\cite{vantrees2002optimum,haykin2014adaptive}. The classification baseline follows classical pattern-recognition methodology~\cite{duda2001pattern}, while the spike-based temporal inference path is motivated by spiking-neuron and neuromorphic-computing models~\cite{maass1997networks,gerstner2002spiking,roy2019towards}. Additional mathematical details are provided in the Appendix.

\subsection{Uniform Linear Array Signal Model}

A uniform linear array consists of $N$ equally spaced sensor elements. For a narrowband plane wave arriving from angle $\theta$, the relative phase progression across the array is determined by the element spacing $d$, the wavelength $\lambda$, and the wavenumber $k=2\pi/\lambda$. With a broadside angle convention, a typical ULA steering vector can be written as~\cite{vantrees2002optimum}
\begin{equation}
    a(\theta)
    =
    \begin{bmatrix}
    1 & e^{-jkd\sin\theta} & e^{-j2kd\sin\theta} & \cdots & e^{-j(N-1)kd\sin\theta}
    \end{bmatrix}^{T}.
\end{equation}
For the Phase 1 prototype, the exact objective is not continuous-angle estimation. Instead, the steering-vector model is used to generate physically meaningful array snapshots for a four-sector DOA classification task.

\subsection{Sample Covariance Matrix}

For each simulated source angle and SNR value, the received snapshot matrix is modeled as
\begin{equation}
    X = a(\theta)s + N,
\end{equation}
where $a(\theta)$ is the steering vector, $s$ is the source waveform, and $N$ is additive complex noise. The sample covariance matrix is
\begin{equation}
    R_{xx}=\frac{1}{M}XX^{H},
\end{equation}
where $M$ is the number of snapshots. In expectation, the covariance structure contains spatial information through the rank-one signal component associated with $a(\theta)a^{H}(\theta)$ and a noise contribution determined by the SNR~\cite{vantrees2002optimum,haykin2014adaptive}.

\subsection{Beamspace Feature Extraction}

Beamspace processing maps array-domain information into a set of angular responses. For a steering vector $b(\phi)$ evaluated at grid angle $\phi$, a simple beamspace energy feature can be represented as
\begin{equation}
    p(\phi)=b^{H}(\phi)R_{xx}b(\phi).
\end{equation}
Evaluating $p(\phi)$ on a fixed angular grid produces a compact real-valued feature vector. In Phase 1, this feature vector is used for coarse sector classification rather than fine DOA estimation~\cite{vantrees2002optimum}.

\subsection{Nearest-Centroid Classification}

The non-spiking baseline uses a nearest-centroid decision rule. If $x$ is a normalized feature vector and $\mu_c$ is the training-set centroid for class $c$, the baseline decision is
\begin{equation}
    \hat{c}=\arg\min_{c}\|x-\mu_c\|_2^2.
\end{equation}
This classifier is intentionally simple and interpretable. It provides a useful reference for measuring how much accuracy is lost when continuous-valued features are converted into sparse spike trains~\cite{duda2001pattern}.

\subsection{Rate-Based Spike Encoding}

After normalization, each feature component is mapped to a spike probability. For feature component $z_i \in [0,1]$, the spike at time step $t$ can be modeled as
\begin{equation}
    s_i[t] \sim \mathrm{Bernoulli}(z_i).
\end{equation}
The time-average spike count approximates the original normalized feature value:
\begin{equation}
    \mathbb{E}\left[\frac{1}{T}\sum_{t=1}^{T}s_i[t]\right]=z_i.
\end{equation}
This representation introduces stochastic quantization error but creates a sparse temporal signal appropriate for hardware-facing inference experiments~\cite{maass1997networks,roy2019towards}.

\subsection{LIF-Inspired Temporal Inference}

The LIF-inspired classifier accumulates spike-driven evidence over time. For class $c$, the membrane evidence follows
\begin{equation}
    v_c[t]=\alpha v_c[t-1]+i_c[t],
\end{equation}
where $\alpha$ is the leak factor and $i_c[t]$ is the spike-driven input current. A higher leak value preserves past evidence more strongly, while a shorter time window reduces latency but may reduce classification accuracy. This leaky temporal accumulation is a simplified hardware-facing abstraction of LIF-style dynamics~\cite{gerstner2002spiking,roy2019towards}.

\subsection{Stable-Decision Latency}

The classifier produces a class decision at each time step by selecting the largest membrane value:
\begin{equation}
    d[t]=\arg\max_{c}v_c[t].
\end{equation}
The stable-decision latency is defined as the earliest time step after which the decision remains equal to the final decision. This metric provides a practical way to evaluate whether the temporal classifier can support early-exit or adaptive-latency edge inference~\cite{roy2019towards}.

\section{Signal Model and Dataset}

The Phase 1 dataset is generated using a narrowband single-source ULA model. For each source angle $\theta$ and SNR value, the received array snapshot matrix is modeled as
\begin{equation}
    X = a(\theta)s + N,
\end{equation}
where $a(\theta)$ is the ULA steering vector, $s$ is a complex narrowband source signal, and $N$ is circular complex additive white Gaussian noise. The sample covariance matrix is computed as
\begin{equation}
    R_{xx} = \frac{1}{M}XX^{H},
\end{equation}
where $M=128$ snapshots. The generated dataset and resulting artifacts are part of the reproducible Phase 1 implementation~\cite{molhem2026embeddedai}.

A compact beamspace feature vector is extracted from the covariance matrix by evaluating spatial energy over a fixed angular grid. The features are normalized using training-set statistics before classification or spike encoding.

\section{Spike Encoding and LIF-Inspired Inference}

Normalized beamspace features are converted into binary spike trains using rate-based encoding. A larger normalized feature value corresponds to a higher probability of spike emission across the time window. This representation is sparse and temporal, making it a useful abstraction for later hardware-oriented experiments~\cite{maass1997networks,roy2019towards}.

The LIF-inspired classifier is implemented as a class-level leaky membrane accumulator. It is not a biologically detailed SNN. Instead, it is a hardware-facing approximation in which each class accumulates spike-driven evidence over time. The membrane state can be interpreted as
\begin{equation}
    v_c[t] = \alpha v_c[t-1] + i_c[t],
\end{equation}
where $v_c[t]$ is the membrane value for class $c$, $\alpha$ is the leak factor, and $i_c[t]$ is the spike-driven input current at time step $t$~\cite{gerstner2002spiking}.

The fixed Run 003 configuration used
\begin{equation}
    T=20, \qquad \alpha=0.97.
\end{equation}
It achieved
\begin{equation}
    \text{Accuracy}_{\text{LIF, fixed}} = 0.825000,
\end{equation}
with mean stable-decision latency
\begin{equation}
    \bar{L} = 6.423810 \text{ time steps}.
\end{equation}

\section{Engineering Interpretation}

The parameter sweep confirms a clear accuracy--latency design trade-off. Increasing the spike time window generally improves classification accuracy because the rate-coded representation has more time steps to approximate the original continuous feature vector. However, a longer time window can increase temporal budget and stable-decision latency.

The leak factor controls evidence retention. Higher leak values preserve accumulated information better. In this prototype, the best LIF accuracy occurs at $T=40$ and leak $=0.99$. The best LIF result improves over the fixed Run 003 configuration but remains below the continuous nearest-centroid baseline. This result is expected and useful: spike-based inference trades some continuous-valued accuracy for sparse temporal processing and explicit latency control~\cite{roy2019towards}.

\section{Conclusion}

The Phase 1 Python prototype successfully establishes an end-to-end DOA-sector inference pipeline based on a physics-derived ULA signal model. The nearest-centroid classifier demonstrates that compact beamspace features provide strong sector-level DOA information, achieving 86.9\% test accuracy.

The spike-based path did not improve raw classification accuracy over the continuous nearest-centroid baseline. The baseline achieved 86.9\% accuracy, while the fixed LIF-inspired configuration achieved 82.5\%, and the best LIF configuration from the parameter sweep achieved 84.17\%. However, the value of the spike-based formulation is architectural rather than purely accuracy-based. It converts continuous beamspace features into sparse temporal spike trains, enables leaky evidence accumulation, exposes stable-decision latency as a measurable output, and creates a tunable accuracy--latency design space through the spike time window and leak factor.

Therefore, the Phase 1 spike-based result should be interpreted as a hardware-aware embedded-AI baseline, not as an accuracy-improving replacement for the continuous classifier. Its main contribution is the transformation of DOA-sector inference into a sparse temporal decision process suitable for later neuromorphic, PYNQ, FPGA, or Vitis HLS-oriented exploration. The source code and generated Phase 1 artifacts are preserved for reproducibility in the project repository~\cite{molhem2026embeddedai}.

\section{Additional Theoretical Details}

\subsection{ULA Steering Vector and Phase Progression}

For a ULA with inter-element spacing $d$, the path-length difference between adjacent sensors is $d\sin\theta$ under the broadside convention. The corresponding phase shift is
\begin{equation}
    \psi(\theta)=kd\sin\theta=\frac{2\pi d}{\lambda}\sin\theta.
\end{equation}
For half-wavelength spacing, $d=\lambda/2$, this becomes
\begin{equation}
    \psi(\theta)=\pi\sin\theta.
\end{equation}
This phase progression is the physical basis for the steering vector used to generate DOA-dependent array snapshots~\cite{vantrees2002optimum}.

\subsection{Beamspace Energy Interpretation}

The beamspace response
\begin{equation}
    p(\phi)=b^{H}(\phi)R_{xx}b(\phi)
\end{equation}
can be interpreted as the output power of a conventional beam steered toward grid angle $\phi$. If the grid steering vector is aligned with the true source direction, the response tends to be larger. Therefore, the vector of grid responses provides a compact angular signature for sector classification~\cite{vantrees2002optimum}.

\subsection{Nearest-Centroid Rule as a Linear Score}

The nearest-centroid decision rule can be expanded as
\begin{align}
    \hat{c}
    &=\arg\min_c \|x-\mu_c\|_2^2 \\
    &=\arg\min_c \left(x^Tx -2\mu_c^Tx + \mu_c^T\mu_c\right).
\end{align}
Since $x^Tx$ does not depend on class, the equivalent decision is
\begin{equation}
    \hat{c}=\arg\max_c \left(2\mu_c^Tx-\|\mu_c\|_2^2\right).
\end{equation}
This form is useful for the LIF-inspired implementation because it can be interpreted as class evidence accumulation using class-dependent weights and biases~\cite{duda2001pattern}.

\subsection{Spike Encoding Statistics}

For rate-based encoding, the spike count for feature $i$ over $T$ time steps is
\begin{equation}
    K_i=\sum_{t=1}^{T}s_i[t].
\end{equation}
If $s_i[t]\sim \mathrm{Bernoulli}(z_i)$, then
\begin{equation}
    \mathbb{E}[K_i]=Tz_i,
\end{equation}
\begin{equation}
    \mathrm{Var}(K_i)=Tz_i(1-z_i).
\end{equation}
Therefore, a longer spike window reduces relative stochastic error but increases the temporal budget~\cite{maass1997networks,gerstner2002spiking}.

\subsection{LIF Leak and Latency Interpretation}

The LIF-inspired update
\begin{equation}
    v_c[t]=\alpha v_c[t-1]+i_c[t]
\end{equation}
acts as a leaky temporal integration of evidence. When $\alpha$ is close to one, previous evidence is retained for more time steps. When $\alpha$ is smaller, the classifier reacts more strongly to recent spikes but may lose accumulated evidence more quickly. This explains why the Phase 1 parameter sweep uses both $T$ and $\alpha$ as design variables~\cite{gerstner2002spiking,roy2019towards}.
